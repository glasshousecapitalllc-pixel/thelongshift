# The streams on WhatsApp

One WhatsApp Community holds everything. Inside it, one group per room and stage. The site's "Join on WhatsApp" buttons point at the groups' invite links, which you paste into `config.js`.

Do this from the phone that will own the Community. Whoever creates it is the admin, and the admin's number is visible to members, so use the number you are happy to run this from.

## Open one group first, not sixteen

Sixteen empty groups is the Dadsnet forum again. Open one, fill it, then open the next when men at another stage ask. The one to open first is the one the evidence says men already queue for:

**Money, separated dads.**

Second, when asked: Chat for whichever town has a night. Third: Money, first year.

## Steps

1. WhatsApp, Communities tab, New community. Name: `The Long Shift`. Description: paste the Community description below. Picture: anything plain; the name does the work.
2. The Community comes with an announcement group only admins can post in. Use it for one line a week at most. Pin the house rules there.
3. In the Community, Add group, Create new group. Name it exactly as in the list below. Paste the matching group description. Settings: Edit group info, admins only. Send messages, all members. Disappearing messages: off. Members can add others: off, so every man comes through the link or an invite.
4. Group info, Invite via link, Copy link. The link looks like `https://chat.whatsapp.com/...`.
5. In `config.js`, find the room and stage, replace `null` with the link in quotes, and write a `who` line, for example `"12 men, mostly Yorkshire"`. Save. The page now shows "Join on WhatsApp".
6. Sit in the group yourself for the first fortnight. The first week is you and two men and silence. Post the Monday question anyway.

If a link ever leaks somewhere you don't want it, Group info, Reset link. Then update `config.js`.

```

```

## Admin rules for yourself

- Reply to the first message from any new man within the day, even with one line. Silence is why forums die.
- Remove anyone selling or screenshotting on the first offence. Say why in the group. Everyone else relaxes when they see the rules are real.
- A man in crisis gets a private message from you with the Samaritans number and a question about tonight, not a group pile-on. Then check the next day.
- You are not the service. You are the bloke on the same shift. Point at StepChange, Acas, the Child Maintenance Service, the GP, and let them be the service.
- When a group passes about 40 regulars, find the man who answers most and make him admin. That is how it survives you.

## Limits worth knowing

- A WhatsApp group holds about a thousand people; a Community holds a few thousand. Nowhere near a problem yet, and if it ever is, that is the day to think about Discord.
- WhatsApp shows phone numbers to other members unless they have hidden them in privacy settings. Say so in the Community description if it worries anyone; most men at this stage care less than you'd think.
- Invite links are public once pasted into the site. Anyone can join. The admin rules above are the moderation.
